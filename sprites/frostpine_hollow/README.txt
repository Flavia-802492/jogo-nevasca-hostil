Frostpine Hollow - top-down 16x16 snow and winter tileset, v1 (seed 1)

Contents
- 24 base tiles: snow, path, ice, water, dirt, cabinfloor (4 variants each).
  Variants of a terrain share identical edges, so you can mix them freely.
- Animated tiles: water (4 frames per variant, 12 extra frames
  in tiles/animated/). The frames keep the tile edges fixed, so they join the transitions cleanly.
- 80 transition tiles in 5 corner sets: snow/path, snow/ice, ice/water, snow/dirt, cabinfloor/snow.
- 34 wall tiles (logs, stone) on a transparent background, so they sit on a layer
  above any floor. Each set has 16 corner tiles plus its extra pieces (tile ids 16+).
- 32 props with outlines and soft shadows (props/, props_sheet.png, props.json).
  3 fire and light props are animated (4 frames, props/anim/).
- maps/frostpine_hollow_demo.tmx: a sample map (Ground, Walls and Props layers).
  scene.png is that map rendered.
- palette.hex / palette.png: the 29-colour palette every asset uses.
- Every tile also ships as its own PNG under tiles/.

Using it in Tiled
- Open the demo map, or add tilesets/*.tsx to your own map. Animations play in Tiled.
- trans_*.tsx and walls_*.tsx have corner terrain sets, so the Terrain Brush picks the
  right tile automatically. Paint walls on their own layer above the ground.

Other engines
- Corner tile index = TL*8 + TR*4 + BR*2 + BL (1 = first terrain / wall, 0 = second / empty),
  laid out left to right, top to bottom, 4 columns. Use it to set up autotiling in Godot,
  Unity, GameMaker or LDtk.

How it was made
- Every tile is generated by our own Python code from a fixed 29-colour palette.

All PNGs are 32-bit RGBA.
